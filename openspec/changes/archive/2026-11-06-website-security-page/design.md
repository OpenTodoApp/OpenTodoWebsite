# Design

## D1. Link rows, no cards
A trust page is read to find a document. Each group is a heading and hairline rows: an icon, the linked title, one line saying what is behind it, an optional note ("For 1.0"). Rows without a link are the documents not yet published; they get their link when the bundle carries `docs/security/`.

## Build and download size
One small page; no script.

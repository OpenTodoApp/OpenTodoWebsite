# Design

## D1 The web app first on `/apps/`
The steps are hairline rows, one per platform, taken from the app's install guide; push is described only as `push-notifications` documents it (iOS 16.4 or later, installed app only). The store section keeps the badge, the greyed buttons and the paragraph about the first version.

## D2 `/ecosystem/` as link rows
The page reuses `LinkRows`, with the status in the row's note: Available, Submitted, in review, or what is true otherwise (Template ready, By hand or BRAT, HACS, From source). Statuses follow the self-hosting guides of the pinned release. It stays English, like the other technical pages. Packages not released yet (the n8n nodes) are not listed.

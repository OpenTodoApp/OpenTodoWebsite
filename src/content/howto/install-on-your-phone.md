## What you need

<!-- no-claim -->
- Your OpenTodo address, and to have signed in once in the browser.
- A server on a secure address (one starting with `https://`). If the browser offers no install option at all, that is the reason; ask whoever runs your server. [Installing the app](/docs/install-app/)

## Steps

1. **iPhone or iPad:** open the address in Safari, tap the Share button (the square with an arrow), scroll down and tap **Add to Home Screen**, then **Add**. [iPhone and iPad](/docs/install-app/#iphone-and-ipad)
2. **Android:** open the address in Chrome, open the browser menu (⋮) and tap **Install app** (on some versions **Add to Home screen**). [Android](/docs/install-app/#android)
3. From now on, open OpenTodo from its icon. It starts without a connection and keeps a full copy of your tasks on the phone. [Keep using it offline](/docs/install-app/#keep-using-it-offline)
4. To get reminders while the app is closed, open **Settings → Notifications** in the app, turn on **Enable notifications on this device** and send a test notification. On an iPhone this works only in the installed app. [Get reminders when the app is closed](/docs/notifications/#get-reminders-when-the-app-is-closed)

## If it does not work

- No install option in the menu: the address is not `https://`, or you are in a browser that does not install web apps. On an iPhone use Safari; on Android use Chrome, Edge or Samsung Internet. [I can't install the app](/docs/troubleshooting/#i-cant-install-the-app-or-add-a-passkey)
- The icon opens an old version: close the app completely and open it again; it updates itself when your server is updated. [Updates](/docs/install-app/#updates)

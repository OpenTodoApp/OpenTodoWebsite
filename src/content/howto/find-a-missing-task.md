## Check these, in order

1. **A filter above the list.** If **Quick wins**, **Under 30 min**, **Over 1 h** or **Unestimated** is switched on, the list shows only matching tasks. Select it again to clear it. [A task seems to be missing](/docs/troubleshooting/#a-task-seems-to-be-missing)
2. **Completed.** It may have been ticked off by accident. Open **Completed** and reopen it. [A task seems to be missing](/docs/troubleshooting/#a-task-seems-to-be-missing)
3. **Trash.** It, or its project, may have been deleted. Restore it from there. [Restore something from the Trash](/docs/trash-and-history/#restore-something-from-the-trash)
4. **An archived project.** Tasks of archived projects do not appear in Today or Upcoming. Bring the project back from **Settings → Projects**. [Bring back an archived project](/docs/trash-and-history/#bring-back-an-archived-project)
5. **A folded parent or section.** Select the small arrow to unfold it. [A task seems to be missing](/docs/troubleshooting/#a-task-seems-to-be-missing)
6. **A shared project you left or were removed from.** Ask its owner. [A task seems to be missing](/docs/troubleshooting/#a-task-seems-to-be-missing)

## Search for it

- Open **Filter** (<kbd>g</kbd> then <kbd>f</kbd>) and type `search: word`; add `& completed` to include finished tasks. [Find a task by a phrase in its title or notes](/docs/filters/#8-find-a-task-by-a-phrase-in-its-title-or-notes)
